{%- comment -%} head.html — all content, driven by page front matter. The main job here is emitting a COMPLETE set of Open Graph and Twitter Card tags so a link pasted into Bluesky, Facebook, iMessage, etc. renders a real preview card with an image, title, and description. Fallback chain for each field: - page.title -> site.title - page.description -> site.description - page.image -> site.og_default_image -> omitted entirely Social scrapers reject relative image URLs, so we run everything through absolute_url. IMPORTANT (fixed 2026-07-17): og:image must NEVER point at a file that does not exist. This previously hard-defaulted to /assets/images/og-default.jpg, which was never created — so every page advertised a 404 as its preview image, which is worse than having no image at all. The default now comes from site.og_default_image in _config.yml, and if that is unset the image tags are omitted cleanly and the card degrades to a text card. To set a site-wide default: drop a JPEG (NOT a WebP — see the Bluesky note in admin/config.yml) into /assets/images/ and uncomment og_default_image in _config.yml. ~1200x630 is the ideal shape. {%- endcomment -%} {%- assign page_title = page.title | default: site.title -%} {%- assign page_description = page.description | default: site.description -%} {%- assign page_image_path = page.image | default: site.og_default_image -%} {%- if page_image_path and page_image_path != "" -%} {%- assign page_image_abs = page_image_path | absolute_url -%} {%- endif -%} {%- assign page_url_abs = page.url | absolute_url -%} {%- if page.layout == "post" -%} {%- assign og_type = "article" -%} {%- else -%} {%- assign og_type = "website" -%} {%- endif -%} {% if page.title %}{{ page.title }} | {{ site.title }}{% else %}{{ site.title }}{% endif %} {%- if page_image_abs %} {%- endif %} {%- if page_image_abs %} {%- endif %}
